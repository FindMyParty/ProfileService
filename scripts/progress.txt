## Codebase Patterns
- Migration files use `import { type Kysely } from 'kysely'` (type-only import when sql template not needed)
- Composite PKs use `.addPrimaryKeyConstraint('table_pkey', ['col1', 'col2'])` not `.addColumn(...primaryKey())`
- FK references: `.references('table.column').onDelete('cascade')` chained on `.addColumn()`
- `ifNotExists()` on createTable is used in existing migrations
